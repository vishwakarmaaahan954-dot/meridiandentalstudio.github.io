🦷 Meridian Dental Studio
Welcome to the repo for Meridian Dental Studio! This is a modern, responsive landing page I built for a dental clinic based in Kanpur. The goal was to create a clean, patient-friendly UI that makes checking out services, meeting the team, and requesting appointments as frictionless as possible.

🔗 Live Demo: Check it out here

✨ What's Inside
Modern UI: A clean, calming, and professional visual design.

Fully Responsive: Optimized for desktop, tablet, and mobile viewing.

Services Showcase: Breakdowns of General, Cosmetic, Pediatric, Orthodontic, and Emergency care.

Meet the Team: Profiles for Dr. Pooja Sharma, Dr. Gaurav Kharya, and Dr. C.S. Lakshmi.

Smile Gallery & Patient Stories: Sections dedicated to social proof and treatment results.

Appointment Booking: A clean, interactive UI for requesting visits (demo mode).

🛠️ Tech Stack
I kept things lightweight and fast for this build:

🚀 Running it Locally
Want to poke around the code?

Clone the repo:

Bash
git clone https://github.com/vishwakarmaaahan954/meridiandentalstudio.github.io.git
Open the directory:

Bash
cd meridiandentalstudio.github.io
Open index.html in your browser, or spin it up using VS Code Live Server for hot reloading.
